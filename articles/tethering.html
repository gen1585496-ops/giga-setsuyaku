テザリングの通信量を抑える

最終更新: 2026-09-03

出先でPCをスマホに繋いだら、1時間で数GB消えていた。 テザリングでよくある事故です。原因ははっきりしていて、対策も決まっています。

なぜ一気に減るのか

PCやタブレットは、その回線を「無制限のWi-Fi」だと思って振る舞います。 スマホのアプリは通信量を気にする作りになっていますが、PC側にはその前提がありません。

とくに大きいのは次の3つです。

  • OSの更新 — 数GB単位。繋いだ瞬間に始まることがある
  • クラウドの同期 — 溜まっていたファイルを一気に上げ下げする
  • 動画の自動再生 — PC向けサイトは高解像度の動画を配信する

対策1：接続を「従量制課金接続」に設定する

これが最も効きます。Windowsにも他のOSにも、 「この接続は従量制です」とOSに伝える設定があります。

Windowsの場合、設定 → ネットワークとインターネット → Wi-Fi → 接続中のネットワーク → 従量制課金接続 をオンにします。

これを入れると、OSが自動的に次の動作を抑えます。

  • Windows Updateの自動ダウンロード（重要な更新を除く）
  • ストアアプリの自動更新
  • 一部の同期処理

テザリングを使う前に、一度だけ設定しておけば以後は自動で効きます。 費用対効果が最も高い項目です。

対策2：クラウド同期を一時停止する

OneDrive、Google Drive、Dropboxなどの同期アプリは、 タスクトレイから一時停止できます。 「2時間停止」のような選択肢があるので、テザリング中はそれで止めておきます。

従量制課金接続の設定だけでは、これらのサードパーティ製アプリまでは止まりません。 別途止める必要があります。

対策3：ブラウザ側で読み込むものを減らす

PC向けのWebページは、スマホ向けより重いことがほとんどです。 画像の解像度が高く、埋め込み動画も多くなります。

テザリング中に調べ物をするだけなら、 画像を止めてしまっても困らない場面が多いはずです。 詳しくはブラウザ設定だけで通信量はどこまで減るかにまとめています。

対策4：親機側でも節約する

見落としがちですが、テザリング中もスマホ本体は通信しています。 子機に帯域を回したいなら、親機側のバックグラウンド通信も止めておくと確実です。

Androidのデータセーバーを有効にしておけば、この点はカバーできます。

それでも足りないなら

テザリングを常用するなら、そもそもの容量設計を見直したほうが確実です。 プランによってはテザリングに個別の上限が設けられている場合もあります。 契約内容を一度確認してください。 観点は料金プランの選び方チェックリストにまとめています。
